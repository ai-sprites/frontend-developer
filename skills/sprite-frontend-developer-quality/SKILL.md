# 前端质量检查

让检查回答当前改动是否破坏用户结果，使用项目现有工具，避免为小改动创建新的质量平台。本实践独立于角色和其他 Skill。

- 交互、浏览器、键盘及无障碍回归：读 [行为检查](references/behavior.md)。
- 性能、请求失败、错误信号和客户端风险：读 [性能与错误](references/performance-errors.md)。

先从差异找出可能受影响的行为，再选检查。执行后报告实际命令或操作、观察结果和未覆盖部分，不用静态格式检查冒充浏览器验证；需要保留证据时才落盘。
